# 🎯 Number Guessing Game (Java)

A simple, interactive number guessing game developed using Java. The computer generates a random number between 1 and 100, and the player must guess it within 7 attempts.

## ✨ Features

- 🎲 Random number generation between 1 and 100
- 🔢 Maximum of 7 attempts per round
- ⬆️ Hints: Too High or Too Low
- ✅ Input validation for invalid entries
- 🔄 Option to play multiple rounds
- 🏁 Displays the correct answer when the player loses

## 🛠️ Technologies Used

- Java
- Scanner class
- Random class
- Loops and conditional statements

## 📋 Requirements

- Java JDK installed on your computer
- Visual Studio Code or any Java-supported IDE

## 🚀 How to Run

**1. Clone the repository**
```bash
git clone YOUR_REPOSITORY_URL
```

**2. Open the project folder**
```bash
cd YOUR_PROJECT_FOLDER
```

**3. Compile the Java program**
```bash
javac NumberGuessingGame.java
```

**4. Run the game**
```bash
java NumberGuessingGame
```

## 🎮 How to Play

1. Run the program.
2. Enter a number between 1 and 100.
3. Follow the hints to guess the correct number.
4. You have 7 attempts in each round.
5. Enter `yes` to play again or `no` to exit.
